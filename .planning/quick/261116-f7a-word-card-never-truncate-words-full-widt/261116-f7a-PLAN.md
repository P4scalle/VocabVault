# Quick Task 261116-f7a — Plan

## Problem

On the Dictionary screen, the word-card renders three inline action icons
(folder / flag / delete) as a fixed right-hand column that spans the full card
height. That column steals horizontal space from **every** content row, so:

- The word is clipped (`truncate max-w-[min(10rem,60%)]`) → "Whimsical" shows as "Whimsi…".
- The definition wraps early ("Given to whimsy.") with empty space beside it.
- The flag icon is visually larger than its siblings — it lacks the `text-xs`
  size class that `pi-folder` and `pi-trash` have (so it renders at the
  PrimeIcons default 1rem vs the others' 0.75rem).

## Goal

Words are never truncated and the definition uses the full tile width minus
padding, while all actions stay accessible (44px targets, labels, keyboard).

## Design (confirmed with user)

Collapse the three actions into a single `⋮` (pi-ellipsis-v) kebab button,
top-right, reusing the existing folder-row popover pattern from
`feature-dictionary.html` / `feature-dictionary.ts`. Content column reclaims the
full width. Word on its own full-width line (`break-words`, no truncate). Mastery
/ Needs attention / Flagged badges on their own line **below** the word. The
inline "Flagged" badge stays so flag state is visible even though the toggle
moves into the menu.

Layout:
```
[icon] Whimsical                          [⋮]
       [Mastered]
       / wɪmzɪkəl /
       adj. Given to whimsy.   ← full width
```

## Tasks

### Task 1 — word-card.ts: add overflow-menu state (mirror folder pattern)
- files: libs/vocavault/feature-dictionary/src/lib/word-card/word-card.ts
- action:
  - Import `signal` and `HostListener` from `@angular/core`.
  - Add `protected readonly menuOpen = signal(false)`.
  - `protected toggleMenu(event: Event)`: `event.stopPropagation(); this.menuOpen.update(v => !v)`.
  - `protected closeMenu()`: `this.menuOpen.set(false)`.
  - `@HostListener('document:click')` → if `menuOpen()` then `closeMenu()`.
  - `@HostListener('document:keydown.escape')` → if `menuOpen()` then `closeMenu()`.
- verify: `nx build vocavault` compiles (AOT); no new lint errors.
- done: component exposes menuOpen + toggle/close, matching folder-row semantics.
